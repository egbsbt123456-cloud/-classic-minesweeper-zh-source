# 扫雷经典版 个人记录版

基于用户提供的中文修改版，原作者 Brandon Dusseau，MIT 许可证；版权及 LICENSE 原样保留。

保留经典外观、初中高级、自定义、满屏、首击安全、鼠标与触屏操作。平台提供翻开、插旗、问号三个模式，点按按当前模式执行；同一标记再点清除，滑动和多指不触发格子。插旗后点击已翻开的数字，旗数吻合才展开；错旗会踩雷。电脑不显示模式按钮，手机显示三个模式。

本版删除排行榜、最快分数、名字输入与重置分数。仓库默认是独立单机版，不连接账号后端。启用可选账号接入后，开局关联账号、通关后保存；具体配置见根目录 README.md。直接打开此目录的 index.html 不会保存账号记录。

这是客户端上报的个人单机记录，不是服务端验证的竞技结果。通关会记录难度、棋盘尺寸、雷数、实际用时、服务端完成时间和辅助标记。彩蛋探雷或停表会标注辅助，不设排名。

修复：存储访问异常不再阻止启动；移除旧排行榜缓存读取；图片加载失败或超过 5 秒不再无限等待；音效播放失败不影响游戏；空白连开使用循环避免递归溢出；后台计时按实际经过时间校准；触屏松手抑制合成鼠标重复输入，拖动或多指操作取消本次点击。

平台电脑以 1.5 倍、手机以 2 倍呈现原有经典棋盘，容器随内容变化，大棋盘局部横向滚动。真实手机的触摸体验仍需人工试用。
